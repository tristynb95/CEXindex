Create Role

Name the role, tick the dashboard tabs it can see, then set what it can do in each admin panel. Assign it to users from the Users panel.

Dashboard — what they can see

Unticked tabs are hidden from the dashboard for anyone with this role.

Admin portal — what they can do

None hides the panel, View is read-only, Edit allows changes. Any View or Edit access lets the role open this admin portal.

Existing Roles

Admin and Viewer are built in and cannot be changed. A role that is still assigned to users cannot be deleted.
